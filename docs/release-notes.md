# AeroForge 发布说明

> 面向使用者（非开发者）。当前版本：**v0.7.1**。开发者视角的逐版明细见 `AeroForge-Spec.md` 修订记录。

## v0.7.1 —— 参数化航天器设计与评估平台（M0.5–M6 能力全集）

AeroForge 是一款运行在 Windows 桌面上的火箭设计与性能评估软件：你从几何参数出发搭建运载火箭，
平台即时给出 3D 模型、工程剖面图与**可溯源、带置信区间**的运力结论。本版本覆盖 M0.5 至 M6
的全部交付能力，以「双击即用的桌面应用」形态发布（**断网可完整使用**）。

### 桌面应用

- 双击 `AeroForge.exe` 启动，原生窗口（非浏览器），3D 视口基于 WebGL2 硬件渲染。
- 无需安装 Python / Node；启动后自动选择空闲本地端口，关闭窗口进程即完全退出。
- 除 AI 助手（外部 API，按需自行配置）外，全部功能**断网可用**。

### 参数化建模（几何）

- **母线轮廓编辑器**：2D 轮廓 → 3D 旋转体，九种曲线族（直线/圆弧/椭球/切线卵形/抛物线/
  冯·卡门/幂律/钟形喷管/样条），生成期自动拦截折角缺陷。
- **九段分区装配树**：整流罩、载荷适配器、仪器舱、贮箱、级间段、共底、发动机、尾翼等分区
  建模，共底贮箱（含容积守恒与干涉四重校验）、扁度系数（封头矢高）、完整捆绑助推器布局与
  分离时序几何联动、曲面光顺与曲率分析（曲率梳）、喷管钟形自动派生。
- 3D 视口支持**分级显隐、剖切、爆炸视图**（纯视图操作，不影响计算与导出）。
- **2D 视图组**：整箭纵剖的工程剖面图（固定尺寸标注清单，数值一律后端下发）+ 外观图；
  液面高度随加注比例实时联动。
- **导出**：STEP / IGES / STL / GLB / PNG（3D 快照与 2D 剖面）/ 参数 JSON / 质量表 CSV / 性能 JSON。

### 参数系统与方案诊断

- 十层参数体系（飞行器 / 级 / 发动机 / 贮箱 / 助推器 / 回收 / 发射场 / 轨道 / 气动 / 时序），
  非法参数被拒并给出**字段级**修改建议；循环依赖可检出。
- 显示单位固定一套（kN / t / m / s / km·s⁻¹ / bar / K / kg·m⁻³）。
- 方案诊断阈值可配置（界面「阈值设置」或 `config.toml`），每条标注生效来源。
- 型号名称匹配提示：输入已知型号名即提示载入，载入后全部可编辑并保留来源标注。

### 数据层（GCAT 目录库 + 自建材料库）

- 内置 GCAT（Jonathan C. McDowell）快照目录库：14,481 条火箭/级/发动机记录、三层标签索引、
  发动机族谱；可按国家 / 级数 / 推进剂 / 年代检索。
- 自建材料库十二条（铝锂系 / 不锈钢 / 钛合金 / 复材 / 高温合金），逐条标注来源与数据质量。
- 内置精校模板：**Falcon 9 / Falcon Heavy / 长征五号 / 土星五号**（参数带公开来源标注）。
- 支持 `.eng` / `.ork` / `.rse` 发动机与火箭文件导入。

### 性能评估（计算内核）

- **CEA 预计算表**四种推进剂组合（LOX/RP-1、LOX/CH₄、LOX/LH₂、N₂O₄/MMH），最优 O/F
  工作点求解与效率因子；**计算路径不实时调用 CEA**，毫秒级响应。
- 多级迭代求解（含并联助推器「0 级段」合并规则）、ΔV 瀑布图、任务时序与回收质量代价。
- **LEO / SSO / GTO / GEO 点值运力表**；蒙特卡洛不确定度（P5/P50/P95）；
  **发射场纬度即时重算**（先解析点值、后区间覆盖）。
- 基准精度：Falcon 9 / 长征五号 / 土星五号 运力误差 **< 10%**（anchored 口径，实测
  −9.7% / −1.6% / +0.3%）。

### 优化与对比（M6）

- **多目标优化**（NSGA-II，Pareto 前沿 + 结果溯源）、权衡研究对比表、批量扫描（≤3 轴全因子）、
  逆向设计（给定轨道与运力反推最小 GLOW 构型）。
- 运力供给双模式：锚定表（缺省）与 L2 弹道精算，二者可对照互验。

### AI 助手（可选，M7）

- 右下角悬浮入口；**不配置不出现**——平台不自带任何密钥与服务。
- 在「AI 设置」中填入 OpenAI 兼容服务的 `base_url` / `api_key` / `model` 即可启用
  （密钥只写不回传，界面只显示脱敏形态；明文保存在本机 `%LOCALAPPDATA%\AeroForge\data`，
  不上传、不入日志）。
- 支持自然语言改参与方案诊断：AI 提议的参数修改以**结构化对比块**呈现，
  **必须点「确认应用」才生效**，AI 永不静默改动你的参数。
- 未配置 / 断网 / 上游出错任一情况：AI 入口自动隐藏或给出明确提示，
  **其余全部功能照常可用**（本地方案诊断按钮零 LLM，永远可达）。

## 安装与数据包说明（数据包与代码分离）

AeroForge 的**代码包**与**数据包**是两个独立部分，可分别更新：

| 部分 | 内容 | 安装位置 |
|---|---|---|
| 代码包 | `AeroForge.exe` 及全部程序资源（含 NASA CEA 原生数据表） | 安装器默认 `C:\Program Files\AeroForge` |
| 数据包 | GCAT 数据快照与目录库（`aeroforge.db`）、CEA 预计算表（`data/cea/`） | `%LOCALAPPDATA%\AeroForge\data`（每用户） |

- **NSIS 安装器**（`AeroForge-0.7.1-setup.exe`）默认同时安装两部分；「数据包」组件可单独取消勾选。
- **手工部署数据包**（便携解压场景）：把发布包内 `data/` 目录整体复制到
  `%LOCALAPPDATA%\AeroForge\data`；或设环境变量 `AEROFORGE_DATA_DIR` 指向任意数据目录
  （该目录须含 `aeroforge.db`、`cea/`、`snapshots/`）。
- 数据包缺失时程序不会崩溃：几何建模照常，推进类功能给出明确的「数据包未部署」提示。
- **卸载默认保留**数据包与你的用户数据（母线存档 / 阈值配置 / 产物缓存 artifacts），卸载程序
  弹窗确认后才删除。
- ⚠ **安装路径必须纯英文**：NASA CEA 原生层无法从含中文的路径加载数据表（安装器会在选择
  路径时直接拦截；默认路径已满足）。

## 系统要求

- Windows 10 / 11 x64；约 1 GB 磁盘空间（程序 ~450 MB + 数据 ~10 MB）。
- Microsoft Edge WebView2 运行时（多数系统已内置；缺失时安装器引导安装）。
- 支持 WebGL2 的显卡 / 驱动（3D 视口必需）。

## 已知限制（如实登记）

- 质量估算中 2 个级位（长征五号芯二级、土星五号 S-IVB）的几何干重与公开值偏差较大
  （数据源口径问题，模型持续细化中）。
- 逆向设计限「全级等比缩放」族；批量扫描界面限 3 轴输入（后端支持更多）。
- AI 助手为**可选**功能：依赖你自备的 OpenAI 兼容外部服务与网络；
  未配置 / 断网时自动隐藏入口并回退手工操作（不削弱任何离线能力）。
